Set up automatic forwarding

Easiest on a computer. Gmail asks you to confirm the address first, and we'll show the code right here.

  1. Open Gmail forwarding settings and click Add a forwarding address. Paste your address above and click Next → Proceed.
    Waiting for Gmail's confirmation code…
  2. Back in Gmail, paste the code and click Verify. Leave "Disable forwarding" selected. You're only forwarding grocery emails, not everything.
  3. Pick the stores you order from:
    In the Gmail search bar, paste this, then click the sliders icon and choose Create filter:
  4. Tick Forward it to, choose your crisper address, tick Also apply filter to matching conversations if you want, and click Create filter.
  1. In Outlook on the web, open Settings → Mail → Rules → Add new rule.
  2. Name it "Crisper". Condition: From → add instacart.com, walmart.com, kroger.com, smithsfoodanddrug.com, harmonsgrocery.com (only the stores you use).
  3. Action: Forward to → paste your crisper address. Save.

Some work and school accounts block automatic forwarding. If nothing shows up within a day, use "Forward by hand" or paste a receipt.

  1. On a computer, open iCloud Mail, click the gear icon, then Rules → Add a rule.
  2. If a message is from instacart.com → Forward to your crisper address. Repeat for each store you order from.
